## ✦ Overview

House of Jewelux unites centuries-old Jaipur bench goldsmithing with contemporary international luxury aesthetics. Operating across solid hallmarked metals, liquid platinum-rhodium mirror polishes, thick 18K/22K vermeil, and certified solitaires, the platform delivers a white-glove, digital luxury atelier experience.

---

## ✦ System Architecture & Highlights

- **Modular Backend:** Structured Node.js/Express service in `server/` featuring dedicated controllers, centralized routing, resilient JSON data persistence, and security middleware.
- **Cinematic Frontend:** Vanilla JS SPA engine powered by GSAP 3 & ScrollTrigger for high-performance 60–120 FPS transitions without bulky frameworks.
- **Three Pillars of Precious Adornment:** Editorial royal crimson velvet and gold interactive feature suites for Heritage Craftsmanship, Timeless Elegance, and Global Luxury.
- **Automated QA & Reliability:** 100% test pass rate across all 22 REST API endpoints and verified asset integrity for all 50 authentic products.

## ✦ Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Copy environment configuration
cp .env.example .env

# 3. Start local development server
npm run dev

# 4. Open in browser:
# http://localhost:3000
```
